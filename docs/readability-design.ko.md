# GuideHollow Pick | 가독성 중심 UI 원칙

- 목적: 방문자가 첫 화면에서 **어떤 정보를 찾을 수 있고, 검증 근거가 어디 있는지** 즉시 알 수 있어야 한다.
- 비주얼: 종이색 배경, 진한 글자, 절제된 녹색 강조, 과한 배너 없이 모바일 우선.
- 홈 1열: 브랜드·메뉴 → 명확한 핵심 문장 → 구매 전 3가지 점검 기준 → 실제 공개된 최신 구매 가이드 → 카테고리 → 검증 절차 → 광고 안내.
- 글 1열: 카테고리 경로 → 제목·요약 → 날짜·출처 개수·제휴 여부 → 핵심 결론 → 목차 → 본문 → 검증 제품/공식 자료 → 출처.
- 780px 이상: 긴 본문 오른쪽에 목차를 고정 표시하되 내용 흐름을 방해하지 않도록 분리.
- 780px 이하: 목차를 접이식으로 제공, 상품 비교표는 옆으로 스크롤.
- 최저 본문 기준: 16px 전후, 본문 line-height 약 1.85, 좁은 320px 화면에서도 가로 페이지 스크롤 없이 가독성 유지.
- 광고성 디자인 금지: 검증되지 않은 추천 순위·허위 판매량·별점·할인 타이머·가격 생성 금지. 광고 고지는 글 위쪽에 문장으로 안내.
- 실제 제품 카드가 있을 때는 검증한 근거와 구매 시 단점을 구매 링크보다 먼저 배치한다.
- 기존 공통 네이버 소유확인 태그, HTTPS canonical, `noindex` 준비 상태와 안전한 쿠팡 정적 HTML 파서 동작을 유지한다.
- 본 문서는 디자인 운영 규칙이며, 모바일 가로폭 검증은 실제 320/375/768/1280px 뷰포트에서 추가 확인할 것.
